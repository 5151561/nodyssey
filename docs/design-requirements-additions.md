## 0. 结论摘要

v2 的主干功能词典依然成立,本次新发现集中在五处:

1. **设置 · 联系方式是个功能组**,不是占位:修改邮箱(密码确认 → 邮箱验证码两步)、
   添加手机(站点自身禁用:"手机短信验证API暂不可用")、**Telegram 绑定**
   ("绑定telegram后可以及时提醒未读消息" + 「立即绑定」)。TG 提醒是站点唯一的
   站外通知通道,App 必须呈现。
2. **设置 · 常用偏好**四项:新标签页打开主题帖(Local)、自动夜间模式(Local)、
   夜间模式依据=系统时间(Local)、**启用节日主题(Remote)**;站点明确区分
   Local(本机)/Remote(账号)存储,App 要沿用这个归属标注。
   **设置 · 首页版块**只有 交易 / 生活 / 贴图 三个开关(Remote)。
3. **用户徽章家族**远比"管理"一个丰富:楼主、服主、管理、管理(退休)、
   违规禁止、骗子;楼头时间旁还有 **"edited Xmin ago" 编辑标记**。
4. **站内导航与社区信息**:关于本站=置顶帖(`/about` 渲染为帖子页)、
   隐私协议=独立长文页 `/termsofservice`(约 6.9k 字)、RSS(`rss.nodeseek.com` →
   `www.nodeseek.com/rss.xml`,RSS 2.0 全站源)、sitemap、电报频道/群组、联系邮箱、
   姊妹站 DeepFlood(桌面顶栏一级外链)。侧边栏还有**论坛统计(64902 位 seeker)**、
   **欢迎新用户**(最新 8 个注册用户名)、相关网站外链(LowEndTalk 等 4 个)。
5. **帖子详情补充**:分页条**顶部(#0 下方)与底部各一条**;右缘有悬浮快捷圆钮
   (跳回复框/翻页,具体语义待实测);公告帖标题带红框「只读」标签;#0 互动条含收藏计数。

版块全集确认为 **14 个**:daily 日常 / tech 技术 / info 情报 / review 测评 / trade 交易 /
carpool 拼车 / promotion 推广 / life 生活 / dev Dev / photo-share 贴图 / expose 曝光 /
inside 内版 / sandbox 沙盒 / meaningless 无意义;**内版仅登录可见**(未登录 13 个)。
桌面顶栏一级只放 日常/技术/情报/测评/交易/拼车/推广 + DeepFlood,全集在侧栏。

## 1. 新实测数据词典(补充 v2 §1,字段以本节为准)

### 1.1 设置 · 联系方式(`/setting#contact`)
- **修改邮箱**:两步表单 —— ①"为确保是用户本人,请输入密码" ②邮箱验证:
  「发送验证码」→ 验证码输入 → 「确定」。
- **添加手机**:整块禁用,文案"手机短信验证API暂不可用"。
- **Telegram**:未绑定态文案"暂未绑定telegram,绑定telegram后可以及时提醒未读消息" +
  「立即绑定」按钮。绑定流程与已绑定/解绑态**未实测**(不想在真实账号上产生绑定),
  画板按"未绑定 / 已绑定(显示 TG 用户名 + 解绑)"两态设计并标注假设。

### 1.2 设置 · 常用偏好(`/setting#preference`)
| 项 | 存储 | App 处理 |
|---|---|---|
| 新标签页打开主题帖 | Local | 浏览器概念,App 不适用 —— 画板中删除并标注 |
| 自动夜间模式 | Local | 与 App 已有主题设置合并,归属标 Local |
| 夜间模式依据(系统时间) | Local | App 改为"跟随系统/定时",标注差异 |
| 启用节日主题 | Remote | App 跟随账号同步,新增开关 |

### 1.3 设置 · 首页版块(`/setting#homepage`)
"自定义首页版块":仅 交易 / 生活 / 贴图 三项开关,全部 Remote。
(6g 版块多选是搜索场景;这里是首页 feed 的隐藏开关,两者别混。)

### 1.4 徽章与楼层标记(帖子详情楼头)
- 徽章实测样本:`楼主`(青色描边)、`服主`、`管理`、`管理(退休)`、
  `违规禁止`、`骗子`(红色系)。同一用户可叠多枚(Lloyd = 楼主+服主+管理)。
- 楼头时间旁出现 `edited Xmin ago`(帖与评论均可编辑,v2 只记了私信的编辑标记)。
- 公告帖在列表行标题旁有红框「只读」标签,与锁帖 lock 图标同义,App 统一用锁定态。

## 3. 批次 F — 新画板

1. **f1 关于与社区**(P2,一张):App 关于页 —— 顶部 App 名/版本/检查更新;
   中部社区信息:论坛统计卡、关于本站(帖子深链)、隐私协议、RSS;
   底部外链组:电报频道/群组、联系邮箱、DeepFlood、相关网站。开源许可入口放最末。
   全部外链行带 `open_in_new`,入口挂在「我的 → 关于」与 9a 底部。
2. **f2 隐私协议阅读页**(P2,可与 f1 拼版):长文按 1l 排版渲染,顶栏「返回 / 隐私协议」,
   底部"最新版本生效日期:2022-11-24"样式;降级方案 WebView 承载(标注取舍)。
3. **f3 Telegram 绑定流程**(P1,一张拼版):设置·联系方式进入 —— 未绑定卡(站点文案)→
   点「立即绑定」弹确认(跳转 Telegram)→ 已绑定卡(TG 用户名 + 解绑,解绑二次确认)。
   绑定跳转机制未实测,画板标注"流程假设,开发时按真实 bot 深链校准"。
4. **f4 App 通知设置**(P1,一张,App 增强):站点无推送,App 用后台轮询 + 系统通知渠道。
   设置项:开启通知、轮询频率(15/30/60 分钟)、仅 Wi-Fi、免打扰时段、
   通知渠道分组(@我 / 回复 / 私信 各自开关,映射 Android 通知渠道);
   末尾一行引导"也可绑定 Telegram 获得即时提醒 → f3"。入口在 3a 设置页新增「通知」组。

尺寸、token、备注规则(数据来源/App 增强/站点不存在)与 v2 §4–§5 相同。
