## 0. 给设计方的说明

- **目标**：探索多个视觉方向，不是在现有设计上修补。现有方案「看起来也还行，但不是想要的审美」。
  每个方向请至少做出第 12 节列的「代表屏」，方便横向比较。
- **现状不等于要求**。第 3–5 节列出的色值、字号、圆角、间距都只是现状，写出来是为了让你知道
  改动面有多大，不是让你照着做。
- **功能不能多也不能少**。附录 A 是用登录账号在真实站点上核对过的功能表：站点没有的功能
  （比如转盘抽奖、粉丝数、系统通知分组、相关度排序）不要画；站点有的交互（比如楼层五件套）
  不能省。
- **所有文案用真实中文样本**（等级 Lv1、鸡腿 344/400、星辰 4、签到 +7），别编造数量级不对的数字。
- 技术栈是 Compose Multiplatform + Material 3（1.5 alpha，Expressive）。设计**可以**偏离 Material 的外观，
  但越偏离、自绘的组件越多，实现成本越高。第 11 节有这条轴的说明。

**待用户补充**（设计前最好填上，能省掉很多轮）：
- 现在的设计里具体哪里不喜欢？（配色？密度？圆角？字体？图标？动效？整体「太 Material」？）
- 有没有参考的 App / 网站 / 风格关键词？
- 想保留的东西有哪些？

## 1. 产品是什么

- **Nodyssey**：NodeSeek（国内 VPS / 主机圈论坛）的第三方开源客户端，非官方。
  同一套代码也能连姊妹站 **DeepFlood**（首页顶栏可以切换站点）。
- **平台**：Android 为主；iOS（模拟器已跑通同一套 UI）；桌面 JVM（用于预览设计系统）。
- **语言**：简体中文（原文）、繁體中文、English。英文通常比中文长 30–60%，布局要能容纳。
- **用户**：技术向中文用户，读帖远多于发帖。核心场景：刷首页 → 读长帖（常有跑分报告、代码、表格）→ 偶尔回复、表态。
- **规模**：约 45 个目的地页面，约 30 个弹窗 / 底部面板，1,117 条界面文案。

## 2. 硬约束（不能改的）

### 2.1 站点与功能
见附录 A。最容易画错的几条：
- 楼层互动固定为**点赞 / 投喂鸡腿 / 点踩 / 引用 / 回复**；只有楼主楼（#0）另外有**收藏**；
  自己的楼层把「回复」换成「编辑」。**没有删除、没有举报**。
- 点赞免费无确认；投喂鸡腿扣 1 个（每天 1 次免费），**需要确认**；点踩扣 2 个，**需要确认**。三者都不能撤销。
- 通知只有「互动」（站点的 @我 + 回复主题合并）和「私信」两类。通知行**没有评论正文**，只有「谁在哪个帖子里 @/回复了我」。
- 首页列表行的字段是固定的（见 §7.2），没有摘要、没有配图。
- 用户页没有粉丝数、获赞数、浏览量。

### 2.2 可用性与无障碍
- 正文 ≥16sp，行高 ≥1.65；**不用斜体、不用全大写**（中文没有斜体，斜体统一用字重表达）。
- 对比度：正文与次要信息 ≥4.5:1。
- 触控目标 ≥48dp。
- 系统字号到 200% 不能溢出或截断关键信息。
- 深色模式**不用纯黑**（目前没有 AMOLED 模式；要不要加是开放问题）。

### 2.3 必须照顾的模式（每个方向都要考虑，不必每屏都画）
| 模式 | 现状行为 | 设计要回答的问题 |
|---|---|---|
| 深色 | 全套深色 token | 深色下的层级、品牌色 |
| **墨水屏模式** | 纯黑白 + 3 级灰，强制浅色，无动效、无涟漪、无阴影 | 新方向在只剩黑白灰时还能不能分清层级 |
| **单手模式**（默认开） | 二级页顶部留一块可下拉的大标题区，最多占屏高 40%（类似 One UI） | 大标题区长什么样；关掉时的普通标题栏 |
| 宽屏 ≥600dp | 列表 + 详情双栏；导航栏变侧边导航栏（Rail） | 双栏比例、空详情占位 |
| 阅读字号 | 正文 14–24sp 可调 | 列表行、楼层在最大字号下的样子 |
| 动态取色 / 自定义种子色 / 角色配色 | 见 §3.1 | 新方向是否还支持用户换色？换色的自由度多大？ |
| 系统减弱动效 | 所有动画变为瞬切 | — |

### 2.4 平台
- Android 最低 API 26。iOS 26（图标用 Icon Composer，Liquid Glass 风格）。
- 登录的人机验证（Cloudflare Turnstile）是嵌入的网页小部件，外观不能自定义。
- 一部分功能只能跳站点网页完成（改邮箱、绑定 Telegram、购买邀请码），会进入 App 内的网页页面。

## 3. 当前视觉系统（全部可以重做）

### 3.1 颜色

**配色来源**（优先级从高到低）：
1. 墨水屏模式 → 固定黑白灰（`#FFFFFF` 纸 / `#000000` 墨 / `#E8E8E8` 面板 / `#3D3D3D` 次要文字 / `#5A5A5A` 分割线）
2. 角色配色（手工调的 5 套，每套亮暗各 28 个 token）
3. 系统壁纸取色（Android 12+ Monet）
4. 种子色 → MaterialKolor 算法生成整套配色

**品牌种子色**：石墨青 `#35606E`（预设圆点用 135° 斜切双色，另一半是 `#7E5700`）。

**分类色**：

  技术类（tech / dev / review / info）= 主色容器；交易类（trade / carpool / promotion）= 第三色容器；
  日常类（daily / life / photo-share / meaningless / sandbox）= 次色容器；警示类（expose / inside）= 警示容器。
- **身份徽章**：楼主 = 主色；服主、管理 = 强调色；管理(退休) = 描边空心；违规禁止 = 错误容器；骗子 = 实心错误色。

**写死的特殊色**：
- 图片查看器：底 `#0E0E11`，文字 `#E9E9EE` / `#C9C9D2`，未选中页点 `#5A5A64`。
- 终端（ANSI 跑分输出）：One Dark 底 `#282C34`、字 `#D7DAE0`，另有 16 色前景 + 16 色背景。

### 3.2 字体
- **没有自定义字体**，用系统字体（Android 上是 Roboto + Noto Sans CJK）；代码用系统等宽。
- 层级主要靠**字重**而不是字号。所有数字用等宽数字（tnum）。

| 角色 | 字号/行高 sp | 字重 | 用在 |
|---|---|---|---|
| titleLarge | 22/28 | ExtraBold，字距 −0.3 | 首页顶栏站名 |
| PostTitle | 20/28 | Bold | 帖子详情标题 |
| titleMedium | 15/21 | SemiBold | 列表行标题 |
| titleSmall | 14/20 | SemiBold | |
| **PostBody** | **16/27**（1.69） | Regular，字距 0.2 | 帖子正文 |
| CommentBody | 15/25 | Regular，字距 0.2 | 楼层正文 |
| bodySmall | 13/19 | | |
| labelLarge | 14/20 | SemiBold | 按钮 |
| labelMedium | 13/18 | Medium | |
| labelSmall | 12/16 | | 元信息行 |
| 标签字 | 11/16 | Medium | 版块标签、徽章 |
| Code | 13/20 | 等宽 | 代码块 |
| 签名 | 正文 ×0.85 | Regular | 楼层签名 |

- 标题类（display / headline）沿用 Material 默认：57 / 45 / 36 / 32 / 28 / 24sp。
- 中文正文排版：贪心断行（与浏览器一致），中英文之间自动加 0.125em 间距（盘古之白）。
- 阅读字号设置缩放正文、列表标题和元信息；顶栏、按钮等「界面框架」字号不随之变化。

### 3.3 形状
- Material 圆角阶梯：4 / 8 / 12 / 16 / 28dp。
- 头像：**15% 圆角方形**（跟站点网页一致），不是圆形。
- 标签、徽章：6dp。
- 设置分组：外角 18dp、组内接缝 5dp、行间 2dp 缝。
- **状态页插画底形**：每种状态一个不对称的「水滴」形（四角百分比各不相同），比如空态 42/58/40/60、
  网络错误 58/42/55/45。116dp 大小，中间 52dp 图标。
- 表情面板：分组药丸 16dp，格子 10dp。

### 3.4 间距与尺寸
- 间距阶梯：4 / 8 / 12 / 16 / 24 / 32dp。
- 头像：列表行按「标题一行 + 标签一行」的高度自动算（约 36–40dp）；楼层 28dp；楼主楼 40dp；个人页 64dp。
- 正文最大宽度 640dp，居中。
- 帖内图片最大高 520dp，超出部分裁掉并加渐变和提示。
- 密度目标：360×800 屏上首页一屏放下 **9–10 行**。

### 3.5 动效
- Material 3 Expressive 动效方案（弹簧），代码里不写死时长。
- 列表 → 详情：**共享元素**过渡（标题、头像、作者名、版块标签从列表行飞进详情头部）；双栏和墨水屏下关闭。
- 首页滚动时底部导航栏隐藏；详情页滚动时浮动工具栏收起。
- 系统减弱动效 / 墨水屏：全部瞬切。

### 3.6 图标
- 约 80 个手工内嵌的 Material Symbols（圆角 outlined，选中态 filled）。没有自定义图标集。

## 4. 组件清单

每一个都需要在新方向里重新定义外观。括号里是代码名。

**列表与行**
- **帖子行**（ThreadRow / PostRow）：左头像 · 标题（最多 2 行）· 元信息流式行 · 可选辅助行 · 可选尾部。
  已读 / 未读两种标题样式；置顶行有底色、头像位换成图钉。
- **楼层**（CommentRow）：头像 · 名字 · 徽章（最多 3 个 + "+N"）· 时间（含「已编辑」）· 楼层号 · 正文 · 签名 · 操作行。
- **通知行**、**私信会话行**、**用户行**、**流水行**（鸡腿 / 星辰）、**管理记录行**、**浏览历史行**、**收藏行**（带离线状态环）。
- **设置行**（分组圆角卡片）：图标 · 标题 · 副标题 · 值 / 开关 / 箭头；单选行；分段按钮（2–3 选 1）。
- **骨架屏**（列表加载用骨架，不用转圈）。

**标签与徽章**
- 版块标签（4 色族）、身份徽章（6 种语气）、锁帖徽章（已锁 / Lv N 可见）、推荐阅读标记（菱形）、
  「N 条新回复」药丸、未读红点 / 数字角标（99+）、「有新版本」小点、Local / Remote 存储徽章。

**导航与框架**
- 底部导航栏（3 项：首页 / 通知 / 我的，通知带角标）；宽屏侧边导航栏。
- 首页顶栏：排序按钮 · 站点切换（NodeSeek / DeepFlood 下拉）· 搜索。
- **单手大标题栏**（OneHandTopAppBar）：约 30 个二级页在用。
- 版块条：横向滚动的筛选药丸 + 展开/收起按钮；展开后换行排列；长按进入拖动排序 / 移出首页的编辑态。
- Tab 栏（通知、搜索、用户页、关注粉丝）。
- **翻页浮动工具栏**（上一页 · 「N / 总页数」· 下一页）+ **跳页底部面板**（页码 / 楼层切换、数字输入、「上次阅读」「最新」快捷项）。
- FAB：发帖、回复、新建私信、转账、全部下载（全是 Extended FAB）。
- 下拉刷新（顶部）、上拉加载新回复（帖子底部）。

**输入**
- 搜索框（折叠式头部）。
- **编辑器工具栏**：11 个动作（加粗 / 斜体 / 删除线 / 标题 / 行内代码 / 引用 / 列表 / 链接 / @ / 图片 / 表情），
  按键 48dp（回复面板里 42dp），末尾扳手打开**自定义工具栏面板**（拖动排序、加入 / 移出）。发帖、回复、私信三处各存一份布局。
- **内容 / 预览 / 对照**三段切换。
- **表情面板**：替代键盘，分组药丸（最近使用 / AC娘 / 洋葱头 / 小黄鸡 / Fluent），6 列网格，退格键。
- **附件托盘**：缩略图 + 上传进度 / 成功 / 等待 / 失败重试。
- 私信输入栏（Markdown 开关 + 发送）。
- 两步验证 6 格验证码输入；密码强度条；颜色选择器（色相条 + 彩度/明度平面 + 十六进制）。

**反馈**
- 状态页（StatusView：插画底形 + 标题 + 说明 + 主按钮 / 次按钮 + 脚注）。
- Snackbar（带「去验证 / 登录 / 重试 / 撤销」动作）、Toast。
- 加载指示（Expressive 的形变 LoadingIndicator；追加加载用 22dp 小转圈）。
- 花费确认弹窗（SpendConfirmDialog：当前余额 / 花费 / 余后，还差 N）。

**卡片**
- 资源卡（鸡腿 / 星辰 / 等级）、等级进度卡、今日额度卡（4 条进度）、签到按钮（3 态）。
- 主题预览卡、更新卡、网络自检报告块。

## 5. 帖子正文排版（富文本）

这是用户停留最久的地方，也是最值得花力气的地方。正文由原生组件绘制（不是 WebView），要设计的块：

| 块 | 现状 |
|---|---|
| 段落 | 16/27sp，可选中复制 |
| 标题 H1–H4 | 正文 ×1.375 / 1.25 / 1.125 / 1.0625，Bold；上 18dp 下 6dp |
| 块间距 | 10dp |
| 图片 | 12dp 圆角；比栏窄按原尺寸、否则满宽；最高 520dp，裁切后底部 30dp 渐变 + 白字提示；相邻小图横排（如徽章） |
| 图片加载中 / 失败 / 仅 Wi-Fi 占位 | 132dp 占位块；失败有 6 种原因文案 + 重试 / 用浏览器打开 |
| 代码块 | 容器底色、12dp 内边距、13/20 等宽、不折行横向滚动、右上角复制、可选语言标签 |
| **终端输出**（ANSI 彩色） | One Dark 底，16 色 |
| 引用 | 3dp 竖条（主色 45% 透明）、字号 ×0.94、次要文字色，可嵌套 |
| 列表 | 「•」或「N.」，可嵌套 |
| 表格 | 两种：窄表单行不折（首列固定、其余横滚）；宽表 / 含图表按 CSS 自动布局折行，图片格 120dp 缩略图 |
| 标签页（Tabs） | 次级滚动 Tab + 内容 |
| 折叠（details） | 48dp 标题行 + 旋转箭头 |
| 分割线 | |
| 链接 | 主色 + 下划线 |
| 行内代码 | 等宽 + 容器底色 |
| 斜体 | **用 Medium 字重代替**（不倾斜） |
| 贴图（表情） | 默认 20sp 方块，设置可调 20–90sp；或按原图大小 |
| 楼层引用 `@某人 #3` | 18sp 高的主色容器胶囊，点了跳到那一楼 |

## 11. 建议探索的方向轴

这里只列**可以变的维度**，每条都给出两端，方便你组合出不同方向。没有推荐项。

1. **离 Material 多远**：纯 M3 Expressive（实现最便宜）↔ 保留 M3 骨架、换掉形状 / 字体 / 配色 ↔ 完全自有视觉语言（大量自绘组件，成本高）。
2. **密度**：信息密集（像站点网页、一屏 10+ 行、分割线列表）↔ 宽松（卡片流、大留白、一屏 5–6 行）。可以考虑做成设置项。
3. **色彩**：单一品牌色、克制 ↔ 允许用户换色（现在的 6 预设 + 壁纸 + 自定义）↔ 更强烈的主题 / 角色化。品牌色本身要不要换？
4. **字体**：系统字体 ↔ 引入自定义西文 / 数字字体（中文字体包太大，基本只能用系统）。
5. **形状语言**：圆润（现状，28dp 大圆角、水滴形）↔ 方正 / 锐利 ↔ 混合。头像是否继续用 15% 圆角方形（跟站点一致）。
6. **层级表达**：色调分层（现状，无阴影）↔ 描边 ↔ 阴影 / 毛玻璃（注意墨水屏模式）。
7. **性格**：工具感、冷静（技术论坛）↔ 社区感、温度、趣味（鸡腿、表情、角色配色）。
8. **详情页底部**：浮动工具栏 + FAB（现状）↔ 常驻回复栏 ↔ 只有 FAB、翻页进菜单。
9. **导航**：3 Tab（现状）↔ 4 Tab（搜索独立）↔ 首页顶部抽屉 / 侧滑。
10. **「我的」页**：功能宫格（现状 21 格）↔ 分组列表 ↔ 仪表盘（资产 / 等级为主）。
11. **图标与品牌**：现在的「灰底黑脸」图标和 App 内的青色品牌之间没有关系，要不要统一。

## 12. 交付要求

**画板尺寸**：主画板 360×800dp；宽屏示意 840×800 或更宽（双栏）。

**每个方向至少要有的代表屏**（亮 + 暗）：
1. 首页（含版块条、置顶行、已读 / 未读、新回复药丸）
2. 帖子详情（楼主楼 + 2–3 个楼层，含代码块、图片、引用、徽章，底部控件）
3. 回复面板（含工具栏和表情面板任一）
4. 通知（互动 Tab）
5. 我的（已登录）
6. 设置主页
7. 一个状态页（网络错误或需要登录）

**方向选定后再补全**：第 7 节所有页面、第 4 节所有组件、第 9 节所有浮层；墨水屏、单手大标题栏、200% 字号、英文版各至少一屏抽查。

**Token 输出**：颜色（亮 / 暗 / 墨水屏）、字体阶梯、圆角、间距、动效。能直接映射到 Material 3 的 ColorScheme / Typography / Shapes 最好，映射不上的单独列出（比如现在的警示色、成功色、版块色族）。

## 附录 A. 真实站点数据词典

（2026-07 至 08 用登录账号实测。设计里所有功能都必须能在这里找到依据。）

**版块（14 个，内版仅登录可见）**：日常 daily · 技术 tech · 情报 info · 测评 review · 交易 trade · 拼车 carpool ·
推广 promotion · 生活 life · Dev dev · 贴图 photo-share · 曝光 expose · 内版 inside · 沙盒 sandbox · 无意义 meaningless。

**首页**：两种排序（按回复时间 / 按发帖时间）；最多 100 页。

**帖子详情**
- 楼头：头像 · 用户名 · 徽章（楼主 / 服主 / 管理 / 管理(退休) / 违规禁止 / 骗子，可叠加）· 相对时间 · 「in 版块」（仅 #0）· #楼层号 · 编辑标记。
- 楼层互动见 §2.1。点赞只能给 7 天内的楼层。收藏可以取消。
- 签名在正文下方，支持 Markdown 链接。
- 数字分页。

**发帖**：标题 · 正文（内容 / 预览 / 对照）· 版块 · 阅读权限（公开 / Lv1…自身等级 / 私有）。表情四组：AC娘 / 洋葱头 / 小黄鸡 / Fluent。站点本身**没有图床**。全局常驻「重要提醒」规则卡。

**通知与私信**：站点 3 组（@我 / 回复主题 / 私信），App 把前两组合并为「互动」。系统消息是私信里置顶的「系统通知」账号会话。私信消息可编辑，没有送达回执。

**鸡腿（主货币）**
- 等级 = 鸡腿数，Lv1→2 需 400、Lv2→3 需 900、Lv3→4 需 1600，Lv5 封顶。
- 流水理由：回帖 +1、发帖 +5、签到 +2~7、被投喂 +1、投喂 −1。每行：变动 · 总计 · 理由 · 时间。
- 今日额度：发帖 0/20 · 评论 0/20 · 签到 · 免费投喂 1 次。
- 签到：每天一次，随机或固定 5 个；有签到榜。
- 邀请码：花 1000 鸡腿买一个，没有邀请码列表。

**星辰（稀有货币）**：流水五类（点赞 / 转账 / 系统 / 管理 / 购买邀请码），金额可正可负，每行带余额。转账：数额 · 收款人 UID · Ref ID，站点会先回显收款人昵称，要二次确认。

**用户空间**：自己 4 个 Tab（概况 / 主题帖 / 评论 / 收藏），他人 3 个（无收藏），他人页有私信和（登录时）关注按钮。概况：加入天数 · 等级 · 鸡腿 · 主题帖数 · 评论数 · Bio · Readme。**没有粉丝数、获赞数、浏览量**。关注 / 粉丝列表不分页、行上无按钮。

**搜索**：帖子 / 用户两类；只能限定一个版块；排序只有回复时间 / 发帖时间，**没有相关度**；不返回结果总数。

**社区工具**：推荐阅读（加精帖列表）· 管理记录（公示表，最多 100 页）· 幸运抽奖（T 楼抽奖**公证**工具，生成链接，不是转盘、不花钱）· 合作商家 · 友站。

**账号设置（站点七组）**：个人信息 · 安全（改密码、登录历史）· 2FA · 联系方式（邮箱 / 手机已禁用 / Telegram）· 屏蔽用户 · 常用偏好（只有「节日主题」是账号级）· 首页版块（交易 / 生活 / 贴图三个开关）。

**站点没有的，不要画**：系统通知独立分组 · 星辰签到 · 推荐算法榜单 · 转盘抽奖 · 活跃值等级 · 树洞 · 每日热榜 · 周报 · 自定义 CSS · 手机短信绑定 · 粉丝数 / 获赞数 · 楼层删除 / 举报 · 私信已读回执。
