Nodyssey

用 Kotlin 和 Jetpack Compose 写成的第三方 Android 客户端。帖子、评论、投票、跑分表都渲染成原生内容，不是把网页塞进 WebView。 A third-party Android client written in Kotlin and Jetpack Compose. Posts, comments, polls and benchmark tables are rendered as native content — not a web page in a WebView.

原生渲染Native rendering

帖子、评论、投票和 NodeQuality 跑分表都是 Compose 组件。正文一律贪心折行并补汉字 / 西文间隙，跑分表保留钉住首列的横向滚动。 Posts, comments, polls and NodeQuality reports are Compose components. Body text greedily wraps with CJK / Latin spacing, and benchmark tables keep a pinned first column.

cloud_off

离线优先Offline first

Room 离线缓存与已读标记、本机浏览历史、每帖记住阅读位置。地铁里没信号也能接着读。 Room offline cache, read marks, local history and a remembered scroll position per post. Keep reading with no signal.

自由软件，欢迎共建Free software, built in the open

Nodyssey 以 GPL-3.0 开源。NodeSeek 没有面向第三方的公开 API，列表、详情与搜索靠解析服务端渲染的页面得来；解析器都有测试覆盖，测试永不访问线上站点。欢迎提 Issue、发 PR，或来 Telegram 群一起折腾。 Nodyssey is GPL-3.0. NodeSeek has no public third-party API, so lists, details and search come from parsing server-rendered HTML; every parser is test-covered and the tests never touch the live site. Issues, PRs and Telegram chatter all welcome.

请求频率保持克制，不做任何自动化刷分行为。Request rates stay restrained, and the app never farms activity automatically.
