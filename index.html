Nodyssey 功能 截图 GitHub

NodeSeek 的
开源 Android 客户端

Nodyssey 用 Kotlin 和 Jetpack Compose 写成，把帖子和评论渲染成原生内容——不是网页套壳。离线缓存、M3 主题、消息通知，一应俱全，全部开源可审计。

Kotlin · Jetpack Compose Material 3 Expressive Android 8.0+ GPL-3.0
⬇ 下载最新版 ★ GitHub 源码 ✈ Telegram 频道

该有的都有

浏览、发帖、互动、离线阅读，一个完整的 NodeSeek 客户端。

🎨

原生渲染

帖子、评论、投票、跑分表都渲染成原生 Compose 内容，正文贪心折行并补中西文间隙，不是把网页塞进 WebView。

📥

离线优先

Room 离线缓存与已读标记、本机浏览历史、每帖记住阅读位置，地铁里没信号也能接着读。

🌗

M3 主题

Material 3 Expressive，动态取色跟随壁纸，也可选预设调色板或自定义种子色，明暗自适应。

💬

完整互动

发帖、评论、编辑自己的内容，点赞 / 反对 / 投喂鸡腿、收藏、每日签到、投票帖阅读与管理。

🔔

消息通知

WorkManager 通知轮询、未读数、@提及与回复、私信会话、关注与粉丝，一处收齐。

🖼️

图片体验

图片全屏预览 / 保存 / 分享，六选一的图床上传，看图发图都顺手。

📐

自适应布局

4 个 tab，宽窗口自动换成侧边 rail，每个 tab 各有独立返回栈，平板折叠屏都合身。

🔒

隐私克制

请求频率克制，不发布账号 Cookie 与抓取凭据，代码全部开源，做了什么一目了然。

界面一览

点上方按钮切换明暗主题，截图会跟着变。
